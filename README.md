# 🔍 Interactive Pokédex

A fully responsive web application that consumes the **PokeAPI** to display Pokémon data. This project demonstrates advanced vanilla JavaScript skills, including asynchronous API handling, dynamic pagination, and complex UI states.

## 🔗 Live Demo
Check out the live application here: [https://cerveraricardo.github.io/Pokedex/](https://cerveraricardo.github.io/Pokedex/)

## 🛠️ Tech Stack
* **Language:** JavaScript (ES6+)
* **Structure:** HTML5
* **Styling:** CSS3 (Flexbox & Animations)
* **Data Source:** [PokeAPI](https://pokeapi.co/)

## 🌟 Key Features
* **Live Search:** Filter Pokémon by name in real-time.
* **Dynamic Pagination:** Efficiently browse through the Pokémon list with a custom-built pagination system.
* **Detailed View:** Click on any Pokémon card to expand it and see detailed stats, types with color coding, and abilities.
* **Smooth Animations:** Integrated CSS keyframes for a polished "expanding" and "closing" card effect.
* **Dynamic Moves List:** Load and toggle a detailed list of moves for each Pokémon on demand.

## 🚀 How to Run Locally
1. Clone this repository.
2. Open `index.html` in your favorite web browser.
3. Use the search bar to find a specific Pokémon or browse using the pagination buttons at the bottom.
